Share links, Markdown, and exported cards contain only bounded numeric fields and a fixed self-reported label; they never include the schemas you pasted. The numeric check catches accidental edits—it is not a signature or proof that a measurement occurred.

What this measures

  • Exact UTF-8 bytes of canonical JSON.stringify(...) output in your browser.
  • Detected model-visible tool count in the pasted payload.
  • Difference versus MCP Lens's checked-in component benchmark at 1,000 tools: 2 tools and 1,114 bytes.
  • A schema-free URL fragment that can reconstruct the self-reported result with an empty textarea.

What this does not claim

  • Schema bytes are not tokenizer tokens, provider bills, latency, or task quality.
  • The live V4 Flash pilot in the repository is a separate three-task measurement with explicit dates and caveats.
  • Shared values are self-reported. Their numeric check is not authentication or independent verification.
  • This page never uploads your schemas; share only what you are comfortable publishing.
